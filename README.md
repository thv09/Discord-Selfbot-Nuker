# Discord Selfbot Nuker

An advanced, high-performance Discord selfbot utility tool built with Node.js and discord.js-selfbot-v13. Features server management commands, mass banning, automated role permission escalation, and quick moderation controls.

*Một công cụ tiện ích tự động hóa hàng loạt và hủy diệt máy chủ Discord hiệu suất cao, được viết bằng Node.js. Các tính năng bao gồm càn quét thành viên, cấp quyền admin hàng loạt cho các role và lệnh quản trị nhanh.*

---

## Tính năng / Features

* **`n.help`**: Hiển thị danh sách các lệnh quản trị hỗ trợ trong server. / *Display the list of supported server management commands.*
* **`n.banall`**: Càn quét và Ban toàn bộ thành viên có thể thao tác trong server. / *Scans and bans all interactable members in the server.*
* **`n.giveallrolesadmin`**: Tự động nâng cấp quyền hàng loạt cho các Role thành quản trị viên kết hợp càn quét thành viên. / *Automatically elevates all roles to administrator permissions combined with mass member sweeping.*

---

## Cách dùng / Usage

1. **Cấu hình Token / Configure Token**: Tạo một file tên là `.env` trong thư mục chứa source code và điền token tài khoản Discord của bạn vào: / *Create a file named `.env` in the source code directory and enter your Discord account token:*
2. **Cài đặt Node.js / Install Node.js**: Đảm bảo máy tính của bạn đã cài đặt sẵn môi trường Node.js. / *Ensure that Node.js is already installed on your computer.*
3. **Cài đặt các thư viện cần thiết / Install required libraries**: Mở cửa sổ lệnh (CMD / Terminal) tại thư mục chứa source code và chạy lệnh: / *Open your command prompt (CMD / Terminal) in the source code directory and run the command:*

```bash
npm install discord.js-selfbot-v13 dotenv
then node main.js

````
